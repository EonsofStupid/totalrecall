# Contributing to TotalRecall

TotalRecall (`trecall`) is a public, pre-release **fork** of
[Qdrant](https://github.com/qdrant/qdrant), maintained by the project owner. It is **not** the Qdrant project
and does not accept external contributions yet.

- Behaviour in the **vector engine core** is almost always upstream Qdrant — report those to
  [qdrant/qdrant](https://github.com/qdrant/qdrant/issues), not here.
- Fork-specific work (the embeddable `trecall` layer, upstream-sync deltas) is tracked in
  [`docs/POAM.md`](docs/POAM.md) and [`docs/UPSTREAM_ALIGNMENT.md`](docs/UPSTREAM_ALIGNMENT.md).

When this repo opens to contributors, this file and a code of conduct will be restored with real contribution
guidelines and a project contact.
